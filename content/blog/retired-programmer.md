プログラマーを辞めようと思う。

これまで自己紹介で「システムエンジニアです」と言うよりも「プログラマーです」とあえて言ってきた。それぐらいプログラマーが好きだった。上流工程やマネジメントはある程度できるようになるとルーチンワークが多く、飽きが来てしまったということもある。プログラミングをしている時のほうが刺激的だったし、そっちのほうでキャリアを積もうとも思っていた。

でも、やはり辞めようと思う。手でコードを書くことは、もう怠惰を美談とするプログラマーがするべきことではない。

仕事では毎日のように Codex を使っている。少なくとももうコードの品質自体には満足している。自分が満足出来るコードを生成してくれる環境が整ってしまったとも言える。 GPT-4 に何度もテトリスを作るのをリテイクさせていた時代が懐かしい。 手でちまちま書くこと自体が非効率でボトルネックで超低速の時代になってしまったのだ。

でも、仕事でも個人でも、何かを作ることをやめることはない。Web サイトを作ることも、ゲームを作ることも、絵を描くことも大好きだからだ。

ただ、もうコードは手で書かない。それはもう分かっているし、自分自身を分からせた。今後は、手足のように AI エージェントを使いこなしていくのだ。

ものづくりは止まらない。

むしろ、自分の中の「こういうのを作ってみたい」は加速している。圧倒的速度で AI エージェントがコードを書いてくれるから、具現化の速度が段違いなのだ。

でも、やはりさみしい。そう。さみしいのだ。手でコードを書き、トライアンドエラーで実装を行い、テストをし、手塩にかけたプロダクトを世に出していく。その泥臭さの素晴らしさ。レガシーの良さを懐かしむと、さみしいのだ。哀愁とも言える。もう二度と手でコードは書かないからこそさみしい。あの脳をフル回転させて何かを作っていた時の楽しさは、やはり忘れられない。

じゃあ手で書けばいいではないか、というと、そういうことではない。それはプログラマーとして恥ずべきことだと思えてしまうのだ。効率の良い方法があるのに、そこから目を背けるのは、また違う話なのだ。

そんな一抹のさみしさを抱えていた時に、この動画を見た。

<https://www.youtube.com/watch?v=vDjW_dRyKXY>

まさに自分の気持ちは、このとおりだった。なんて素晴らしく言語化してくれるのだろう。手でコードを書いていた時代は、素晴らしい体験に満ちた、実りのある時代だったと、表現してくれたのだ。過ぎた日々に喜びをと。そしてそれはもう終わった時代だと受け入れようと。時代の切り替わりに立ち会えたことを喜び、次に続く輝かしいキャリアに目を向けようと。プログラマーではなく、モノを生み出すプロフェッショナルになろうと。

正直ちょっとウルッとしながら動画を見ていた。それぐらい勇気をもらえた。

ありがとう、自分がプログラマーとしていられた時代。

そしてよろしく、未知の未来。

今後も何かを作る人生を。それが今の目標だ。

## おまけ

個人的なプログラマー人生を振り返ろうと思う。

コーディング自体は 2006 年ぐらいからしていた。高校生の時に自分のホームページを作ったのがきっかけだ。その時は Dreamweaver という Adobe のサイト構築アプリから始めた。HTML をさわり、CSS をさわり、CGI や JavaScript に手を出して、プログラミングを楽しんでいた。

自分のホームページを作るきっかけは、自分が描いた絵を載せるページが欲しかったことだ。絵がメインでサイト構築はサブだったが、それでもやはり Web というもの自体に惹かれていたのは覚えている。

そんな経験を活かして、受託開発の会社に Web デザイナーとして新卒入社したが、紆余曲折あり、気がついたらプログラミングが主業務になっていた。

その時は、Flash でガラケーの待ち受け画面を受託開発したり、PHP で e ラーニングのサイトを開発したり、Movable Type で CMS を構築したりしていたが、今思えばこれらの技術も今ではほぼ見ない。Flash に至ってはそもそも消滅してしまった。

その後は PHP → Node.js となり、今でも TypeScript を書くのが一番好きだ。

AI エージェントが TypeScript を生成するのが得意で良かったと今では思う。

今後も AI エージェントを手足のように使いながら、何かものづくりに関われる人生であれば、もう言うことはない。そうなるための努力を怠らないだけだ。

ああ、コーディング、楽しかったな。
