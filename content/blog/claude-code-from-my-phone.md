個人開発では、ノーレビュー、ノールックで開発することにもだいぶ慣れてきたと思ったが、全然甘かった。ノーコードレビュー開発の初心者だった。

先日、スマホアプリでの Claude Code デビューした。

これまではなんだかんだで PC でやっていた。ノーレビュー、ノールックとは言いつつ、lazygit で push するときにちらっとコードを見ていたのだ。

でもスマホでは違う。もうそもそも見られない。どういう改修をしたかなんか追いかけられない。スマホからチャット形式で指示したら、Git につながっている Claude Code 君が勝手に作ってくれる。

main ブランチに push したら、あとは勝手に Cloudflare にデプロイされるから、Claude Code 君を信じて「main にマージしておいて」と言うだけだ。

これはさすがに最初はドキドキした。

なんせ Claude Code 君は `npm run dev` で開発サーバーを見られるけど、僕はなんにも見えないからだ。たまにスクリーンショットが渡されるが、正直、小さくてよくわからない。

たしかにこれは外部ハーネスの出番だなと思った。

もう人間はできる限り関わらないほうがいいんだ。開発には。

スマホから指示を送り、その間はゲームでもなんでも、別のことをして、通知が来たらちょっと返事をするか、「LGTM」と言うだけだ。

だからこそ、本当にノールックでいいように、ハーネスやら CI/CD やらを十分に整備しておく必要があったのだ。

個人開発でパソコンを捨て去ったからこそ、それが初めて身にしみた。

逆に言えば、もう開発にパソコンはいらないかもしれない。スマホだけで十分開発ができてしまう。

なんてワクワクする世界だろうか。

ばんざい！
